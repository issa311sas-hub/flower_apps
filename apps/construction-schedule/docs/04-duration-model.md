# 工期の計算モデル

タイプコード（例 `C2E42`）だけから、基礎工事・躯体工事の稼働日数を計算する式。
過去データ46物件の実測値から導出し、`M_工期` シートに初期値として入っている。

## 計算式

```
稼働日数 = ROUND(基準日数 + 坪係数 × 坪数) + 種類補正
```

### 基準式（C種を基準にした回帰）

| 工程 | 基準日数 | 坪係数 | 平均絶対誤差 | 根拠件数 |
|---|---|---|---|---|
| 基礎 | 6.37 | 0.1075 | **2.2日** | 29 |
| 躯体 | -0.21 | 0.1103 | **0.6日** | 29 |
| 基礎_暦日（参考） | 17.59 | 0.0976 | 4.6日 | 29 |

### 建物種類による補正（日数に加算）

| 種類 | 基礎補正 | 躯体補正 | 件数 | 根拠 |
|---|---|---|---|---|
| C | 0 | 0 | 29 | 基準 |
| R | **+3** | **+1** | 6 | 工事店確認済：基礎・躯体ともCより長い。実測 +2.6 / +0.5 |
| P | **0** | **+1** | 1 | 工事店確認済：基礎はCと同じ、躯体だけ長い |
| D | +1 | 0 | 5 | 実測のみ +1.4 / +0.1 |
| DY | -2 | 0 | 3 | 実測のみ -1.6 / +0.2　**※要確認** |
| M | +5 | -2 | 2 | 実測のみ。大規模は別扱いの可能性　**※要確認** |
| V | 0 | 0 | 0 | データなし。Cと同じ扱い　**※要確認** |

R と P の補正値は工事店さまの証言（「RはCより基礎・躯体とも長い」「PはCより躯体だけ長く基礎は同じ」）と
実測の残差が一致したため、証言を優先して整数に丸めた。

## タイプコードの読み方

```
C 2 E 42
│ │ │ └── 総坪数（坪数欄 ①②の合計とほぼ一致することを確認済み）
│ │ └──── E または F（違いは未確認）
│ └────── 階数
└──────── 建物種類
```

末尾の `E` または `F` の後ろがすべて数字になる位置で区切る。

| タイプ | 種類 | 階数 | 坪数 |
|---|---|---|---|
| `C2E42` | C | 2 | 42 |
| `DYF67` | DY | （表記なし） | 67 |
| `V3F208` | V | 3 | 208 |
| `M2F126` | M | 2 | 126 |

## 精度と限界

### 躯体は信頼できる

平均絶対誤差 **0.6日**、実測46件のうち **45件（98%）が±2日以内**。
坪数との相関がきれいに出ており、そのまま使える精度。

### 基礎はばらつきがある

平均絶対誤差 **2.2日**、±2日以内は **33件（72%）**、最大誤差は7日。
地盤条件・天候・グランドコラムの有無に左右されるため、これ以上は詰められない。
**自動生成後、担当者が微調整する前提**で使う。

### 暦日スパンは自動計算に使わない

「開始から完了までの暦日」は平均絶対誤差 **4.6日**（±2日以内は30%のみ）と精度が出ない。
基礎工事の途中に CO打設・６日養生 による中断が入り、その位置と長さが物件ごとに違うため。

**そのため自動生成では、開始日から稼働日数分を連続で塗る方式にしている。**
実績の色帯は途中で途切れているので、見た目は実物と少し異なる。
養生の入り方が確定したら、中断を再現するよう改良する（→ `03-open-questions.md` Q4）。

### 実測範囲外は外挿になる

実測データは **25〜90坪**。この範囲を外れるタイプ（例 `V3F208`）は外挿になるため、
自動生成の結果画面に `※実測範囲外` と表示される。必ず目視で確認すること。

## モデルの更新方法

工事店さまから正しい日数が得られたら、`M_工期` シートの数値を直すだけで反映される。
コードの修正は不要。

新しい過去データが手に入った場合は、以下で係数を再計算できる。

```bash
python tools/analyze_chart.py <工程表が入っているディレクトリ>
```
