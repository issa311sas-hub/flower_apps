# 現行工程表（ローテーション表）の構造分析

過去データ7ファイル（2026年4月〜8月版、各ファイル7ヶ月分を収録）を機械的に解析した結果。
色・日付・文字列をすべて抽出し、物件横断で規則性を突き合わせて確定させたもの。

## 1. シート構成

| シート名 | 内容 |
|---|---|
| `1` | メインのローテーション表。実データはここに集約されている |
| `４カ月工程表` | 4ヶ月概要ビュー（ほぼ空のテンプレート） |
| `2` / `3` / `4` | 個別ビュー（ほぼ空のテンプレート） |

以降はすべてシート `1` の話。

## 2. 座標系

xlrd（0始まり）と Excel/VBA（1始まり）の対応。**VBA を書くときは右列を使う。**

| 項目 | xlrd | Excel/VBA |
|---|---|---|
| 日付行 | row 2 | **3行目** |
| 日付列（先頭） | col 16 | **17列目（Q列）** |
| 日付列（末尾） | col 232 | **233列目** |
| 物件ブロック開始 | row 4〜 | **5行目〜** |

- 日付列は 7ヶ月分（約215日）が横に並ぶ。
- **月の変わり目に1列だけ日付なしの区切り列が入る**（実測：xlrd col 108, 170）。
  列インデックスから日付を計算してはいけない。**3行目の値を読んで日付↔列の対応表を作ること。**

## 3. 物件ブロック = 6行

1物件が縦6行を占める。`邸名`（末尾が「邸」）が入っている行がブロックの先頭。

### 左側の固定情報（9〜15列目 / xlrd col 9-15）

| ブロック内 | 内容 |
|---|---|
| +0 | 担当GS名、邸名、建設地、基礎業者、躯体業者、電気業者 |
| +1 | GS名、契約番号（例 `NB50212`）、タイプ（例 `C2E42`）、大工名 |
| +2 | 水道業者、`本着` / `お客様納期` ラベル、家具日数、坪数（`①18.4 ②16.2`） |
| +3 | 本着日、お客様納期、和室有無 |
| +4 | 外構業者、足場業者、その他仕様（ZEH+、全館空調、ロフト等） |
| +5 | （空行） |

> 注意: `本着` / `お客様納期` の日付セルは**更新されず残っている物件が多い**。
> 日付の真値は色帯と黒マーカーから取ること。

### 日付エリア（17列目以降）の行の役割

**ここが自動化の中核。** 実測で確定した割り当て：

| ブロック内 | 役割 | 主な色 | 主な文字列 |
|---|---|---|---|
| **+0** | **躯体工事の色帯** | 茶 `(153,51,0)` / 薄紫 `(204,153,255)` | 穴明け、断熱搬入、先床施工、①②大工 |
| +1 | 躯体行の補助 | 白（単発イベント） | UB設置、家具搬入、器具、CL、M3〜M5、2W |
| +2 | 補助 | 白・単発 | 吹付、オークラタイル、６日養生、グラインドコラム |
| **+3** | **コテ工事の黒帯** | 黒 `(0,0,0)` 3〜4日 | （文字なし） |
| **+4/+5** | **基礎工事の色帯**（後半は外構が同じ行を使う） | 青・桃・緑・黄など業者別 | CO、先足、足場、防水、シーリング、乾燥、断熱工事、内部配管 |

> 「上2マス＝躯体 / 下2マス＝基礎」という説明とは、+2/+3 が中間に挟まる点だけ異なる。
> +3 の黒帯は**躯体完了の2〜3日後に必ず3〜4営業日**現れるため、コテ工事と判定した。
> **要確認事項** → `03-open-questions.md` Q1

### 2種類の黒セルの区別

黒は2箇所に出るが**行が違うので機械的に判別できる**。

| 場所 | 長さ | 意味 |
|---|---|---|
| +4/+5 行 | **1日** | **契約上の着工日** |
| +3 行 | 3〜4日 | コテ工事（推定） |

## 4. 色パレット（実測 RGB）

| RGB | 呼称 | 用途 |
|---|---|---|
| `(153,204,0)` | 黄緑 | **日曜・祝日**（全行に塗られる。今回自動化する対象） |
| `(153,51,0)` | 茶 | 躯体チームA |
| `(204,153,255)` | 薄紫 | 躯体チームB / 外構フェーズ2 |
| `(0,0,0)` | 黒 | 契約着工日(1日) / コテ工事(3〜4日) |
| `(0,102,204)` `(255,128,128)` `(0,128,0)` `(255,0,255)` `(255,255,0)` | 青/赤桃/緑/桃/黄 | 基礎業者ごとの色分け |
| `(153,204,255)` | 水色 | 外構フェーズ1 |
| `(255,204,0)` | 金 | 社内行事・タイル工事 |
| `(255,255,255)` | 白 | 単発イベント（家具搬入・CL 等） |
| `(204,255,255)` | 淡水 | 足場・内部足場 |

**業者名と色は1対1に対応しており、同じ色＝同じ業者。**
基礎・躯体とも同一業者が同時に2現場を稼働できないため、
**色ごとに日程が重複していないことが自動チェックの対象になる。**

## 5. 標準的な工程の並び（実測で全物件共通）

```
M1（お客様と土地・配置の最終確認）
  ↓ 約10日
■ 契約上の着工日（黒1マス、+4/+5行）
  ↓ 中央値2日（1〜7日 / 日祝を除く3営業日以内）
▓▓▓ 基礎工事（+4/+5行・業者色）… 途中に CO・６日養生 を含む
  ↓ 先足（先行足場）
  ↓ 中央値4日（2〜11日）
▓▓▓ 躯体工事（+0行・茶 or 薄紫）
  ↓ 足場 → 穴明け（1日）
  ↓ 2日
███ コテ工事（+3行・黒 3〜4日）
  ↓
防水 → シーリング → 乾燥 → 断熱工事 → 内部配管 → 先床施工 → UB設置
  ↓
大工 → 内装 → 家具搬入 → 器具 → CL → クリーンハウス
  ↓
M3 → 2W → M4 → M5（引渡し）
```

`６日養生` の文字列が基礎工事の中に必ず出現する。
コンクリート養生は基礎工事の**内側**にあり、色帯が途切れている区間がそれに当たる。

## 6. 自動化にあたっての含意

1. **日付↔列の対応は3行目から読む**（区切り列があるため計算不可）。
2. **色は行オフセットで意味が変わる**ので、必ず「ブロック先頭行 + オフセット」で書き込む。
3. **日曜・祝日の黄緑は全物件の全6行に塗る**必要がある（物件ごとの例外を除く）。
4. 業者の重複チェックは**色単位**で行えば足りる（業者名の正規化が不要）。
