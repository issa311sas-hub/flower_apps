## 最優先（Phase 2 の前提）

### Q1. 躯体の2段下に出る「黒い3〜4日の帯」はコテ工事ですか？

全物件で例外なく、**躯体完了 → 穴明け(1日) → 2日空け → 黒帯3〜4日** という並びでした。
議事録の「躯体工事の後にコテ工事という別業者の工程が入る」と一致するため、コテ工事と判断しています。

- 契約着工日の黒マス（基礎の行・1日）とは別物として扱ってよいですか？
- コテ工事の業者は基礎・躯体とは別業者ですか？（別なら重複チェックの対象を分けます）

### Q2. 標準工期の数値は妥当ですか？

→ **`02-duration-hypothesis.md` をそのままお渡しして確認いただく**（確認1〜4）。

### Q3. 建物種類コードの意味

`C` `D` `P` `R` `V` `M` `DY` はそれぞれ何を指しますか。また `E` と `F` の使い分けは何ですか。
末尾の数字が総坪数であることは、坪数欄との突合でほぼ確認済みです。

### Q4. 基礎工事の中の「６日養生」

全物件の基礎工事の途中に `６日養生` の文字列がありました。

- これがコンクリート養生（ヒアリング時の「5日くらい置く」）ですか？
- 6日は**暦日**ですか、**稼働日**ですか？
- 物件によって日数が変わりますか？（データ上はすべて「６日」表記でした）

### Q5. 工程の並びはこれで固定ですか？

```
M1 → 契約着工日 → 基礎（CO・6日養生を含む） → 先足 → 躯体 → 足場 → 穴明け
  → コテ → 防水 → シーリング → 乾燥 → 断熱工事 → 内部配管 → 先床施工 → UB設置
  → 大工 → 内装 → 家具搬入 → 器具 → CL → クリーンハウス → M3 → 2W → M4 → M5
```

- この順序は全物件共通と考えてよいですか？
- 各工程の**所要日数**と**前工程からの間隔**を数値でいただけますか？
  （基礎・躯体・コテは実測済みなので、それ以外について）

### Q6. M3 / M4 / M5 / 2W は何ですか？

- それぞれ何の検査・節目ですか？
- M2 が見当たりませんが、存在しますか？
- これらは前工程から自動計算できますか、それとも個別に決まりますか？
