# セットアップ手順

所要 15〜20分。Excel の操作だけで完結します。

## 前提

- Windows 版 Excel（VBA を使うため。Mac 版でも動きますが未検証）
- 現行の工程表ファイル（`.xls`）

## 1. マクロ有効ブックとして保存し直す

1. 現行の工程表を Excel で開く
2. **ファイル → 名前を付けて保存**
3. ファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」** に変更して保存

> `.xls` のままではマクロを保存できません。必ず `.xlsm` にしてください。
> 元ファイルは別名で残しておくことをおすすめします。

## 2. 開発タブを表示する

**ファイル → オプション → リボンのユーザー設定** で、右側の **「開発」** にチェック。

## 3. VBA モジュールを取り込む

> **重要1：モジュールは常に6つまとめて入れ替えてください。**
> VBA はプロジェクト全体をコンパイルするため、1つでも古いままだと
> 「Sub または Function が定義されていません」で止まります。
> 1ファイルだけ差し替える運用はできません。
>
> **重要2：必ず `vba/sjis/` の方を取り込んでください。**
> `vba/` 直下のファイルは UTF-8 です。VBE の「ファイルのインポート」は
> 日本語版 Windows では Shift-JIS として読むため、UTF-8 版を取り込むと
> マクロ名・シート名・判定文字列がすべて文字化けします。

1. **開発タブ → Visual Basic**（または `Alt + F11`）
2. 左のツリーで、対象のブック名を右クリック → **ファイルのインポート**
3. **`vba/sjis/`** フォルダの `.bas` を **6つすべて** インポートする

| ファイル | 役割 |
|---|---|
| `M00_Config.bas` | 座標定数・タイプ解析・共通ヘルパー |
| `M01_Holiday.bas` | 祝日・会社休業日の判定 |
| `M02_Masters.bas` | マスタシートの生成・工期の計算 |
| `M03_PaintHolidays.bas` | 日祝の塗りつぶし |
| `M05_Plan.bas` | 工程の自動生成（基礎・躯体）・重複チェック |
| `M99_Menu.bas` | ボタン用エントリポイント |

4. **参照設定を確認**：VBEのメニュー **ツール → 参照設定** で
   **Microsoft Scripting Runtime** にチェックが無くても動きます（遅延バインディングを使用）。特別な設定は不要です。

### 文字化けしてしまったときの復旧

`Alt + F8` のマクロ一覧に `繝懊ち繝ｳ_...` のような文字列が並んでいたら、
UTF-8 版を取り込んでしまっています。**実行せずに入れ直してください。**
マクロ名だけでなく、コード内のシート名 `"M_業者"` や判定文字列 `"全件"` も
壊れているため、そのまま実行すると文字化けしたシートが作られます。

1. `Alt + F11` で VBE を開く
2. 左のツリーの **標準モジュール** から `M00_Config` 〜 `M99_Menu` を右クリック
3. **「M00_Config の解放」** を選び、「エクスポートしますか？」には **いいえ**
4. 全モジュールを削除したら、`vba/sjis/` から入れ直す

### 開発者向け：Shift-JIS 版の作り方

`vba/` を編集したら、以下で `vba/sjis/` を作り直します。

```bash
python tools/make_import_bas.py
```

CP932 で往復できない文字があるとエラーで止まるので、
文字化けしたまま気づかずコミットすることはありません。

## 4. 工程表シートを指定する

マクロは「どのシートが工程表か」を知る必要があります。
シート名はブックによって違う（`1` だったり `工程表実データ` だったり）ため、指定します。

1. **色を塗りたいシートを開く**（例：`検証用`）
2. `Alt + F8` → **`ボタン_このシートを工程表に設定`** を実行

シート名は**ブックの中に保存されます**（設定用のシートは作りません）。

> 検証用シートで試してから本番シートに移る、といった使い分けができます。
> 対象を変えるときは、対象シートを開いてこのボタンを再実行してください。
>
> 設定はブックに保存されるので、**Excel を閉じる前にブックを保存してください。**

指定しなかった場合は、`1` という名前のシート → 開いているシート、の順で探します。

## 5. レイアウトを検証する（重要）

いきなり塗ると事故るので、まず座標が合っているかを確認します。

1. `Alt + F8` でマクロ一覧を開く
2. **`ボタン_レイアウトを検証`** を実行

以下のような内容が出れば正常です。

```
■ 対象シート : 検証用

■ 日付エリア
  日付の行     : 3 行目
  日付の列数   : 215 列
  先頭         : 17 列目 = 2026/07/01
  末尾         : 233 列目 = 2027/01/31

■ 物件ブロック
  検出件数     : 30 件
  先頭5件:
    5行目  岡﨑 毅邸  [RL50033]  V3F208
      基礎業者 加納 / 躯体業者 丸岩
      本着日 2026/09/01 / 納期 2027/01/20
    ...
```

**日付・物件名・業者名・本着日が実際のシートと食い違う場合は、ここで止めてください。**
`M00_Config.bas` の定数を実際のシートに合わせて直してから先に進みます。

| ずれているもの | 直す定数 |
|---|---|
| 日付の行・開始列 | `ROW_DATE` / `COL_DATE_FIRST` |
| 物件の先頭行・邸名の列 | `ROW_BLOCK_1ST` / `COL_NAME` |
| 基礎業者・躯体業者 | `COL_KISO_VENDOR` / `COL_KUTAI_VENDOR` |
| 本着日・お客様納期 | `COL_HONCHAKU` / `COL_NOUKI` / `ROW_OFS_DATES` |

## 6. マスタシートを作る

`Alt + F8` → **`ボタン_初期セットアップ`** を実行。

以下の**3シートだけ**が追加されます。

| シート | 中身 |
|---|---|
| `M_業者` | 色と業者の対応表。**工程表の業者名をここで引いて色を決めます** |
| `M_例外日` | 例外日。契約番号と日付だけ入力すれば、扱いが反転します |
| `M_工程データ` | 色塗りの元データ。1物件1行で、工程が横に並びます |

> **`M_設定` と `M_工期` は作りません。** 利用者が触るものではないため、
> 中身はマクロの中に持たせました。古い版で作られたこの2枚は、
> 初期セットアップのときに**削除されます**（工程表シートの指定は引き継がれます）。
>
> | 元シート | いまの置き場所 |
> |---|---|
> | `M_設定`（工程表シート名） | ブックの中（画面には出ません）。`ボタン_このシートを工程表に設定` で書きます |
> | `M_工期`（工期の式・種類補正） | `M02_Masters.bas` の `TermDays` / `TypeCorrection` / `TermInterval` |
>
> 工期の日数を変えたいときは `M02_Masters.bas` を直して入れ直してください。

## 7. カレンダーの年を確認する

前年の表を作り替えて使っていると、日付セルに入っている「年」が実際と
違うことがあります（レイアウト検証で 2026年のはずが 2025年と出る場合など）。

そのときは **`ボタン_カレンダーの年を設定`** を実行し、
**日付エリアの先頭列の年**を入力してください。

- 以降は**月日だけ**をシートから読み、年はマクロが振り直します
- 月が戻ったところ（12月→1月）で1年繰り上げます
- `0` を入れると補正をやめ、シートの値をそのまま使います

設定したら **`ボタン_レイアウトを検証`** で日付を確認してください。
「シートの生値」も表示されるので、何が入っているか分かります。

> **年がずれたまま塗ると、本着日やお客様納期が塗られません。**
> 日付が一致する列が見つからないためです。先にここを直してください。

## 8. 日祝の塗りつぶしについて

**日祝を塗る単独のボタンはありません。** 色を塗る処理のなかで一緒に行われます。

| いつ塗られるか |
|---|
| **`ボタン_初期セットアップ`** の最後（工程表シートが決まっていれば） |
| **`ボタン_工程表に色を塗る`** の最初 |

塗る対象は **日曜・祝日・お盆(8/13〜16)・年末年始(12/30〜1/3)** です。
実行結果に件数が出ます。

```
日祝（日曜・祝日・お盆・年末年始）
  塗った 8,640 セル / 見送り 12 セル（別の色が入っていたため）
```

**「見送り」** は、すでに別の色が入っていて上書きしなかったセルです。
社内行事の色を日曜に載せている箇所などが該当します。

> **休みなのは日曜と会社休業日だけです。祝日は稼働日です。**
> 工程表では日程を確認したいので祝日にも色を塗りますが、
> 工期の計算では作業日として数えます。祝日に工事が入っていれば、
> このあとの工程の色塗りが黄緑を上書きします。
> （**塗った黄緑を剥がす処理はありません。**）

> 何度実行しても結果は同じです（塗り直しても増えません）。

## 9. ボタンを配置する（任意）

毎回 `Alt + F8` を押すのが面倒な場合。

1. **開発タブ → 挿入 → フォームコントロールのボタン**
2. 工程表の空いている場所にドラッグして配置
3. マクロの割り当てダイアログで、以下から選ぶ

| ボタン名の例 | 割り当てるマクロ |
|---|---|
| 工程を計算する | `ボタン_工程を計算する` |
| カレンダーの年を設定 | `ボタン_カレンダーの年を設定` |
| 工程表に色を塗る | `ボタン_工程表に色を塗る` |
| 選択行の計算結果をクリア | `ボタン_選択行の計算結果をクリア` |
| 工程の色をクリア | `ボタン_工程の色をクリア` |
| 業者の重複を確認 | `ボタン_業者の重複を確認` |
| 導入状態を確認 | `ボタン_導入状態を確認` |
| このセルは何？ | `ボタン_このセルは何` |

## 使い方

### 例外日を設定する（日曜に稼働する／祝日・平日に休む）

`M_例外日` シートに **契約番号と日付の2列だけ**入力します。
「詳細」列はマクロが日付から判定して書き込むので、触らなくて構いません。

| A 契約番号 | B 日付 | C 詳細（自動） |
|---|---|---|
| NB50212 | 2026/09/06 | 日曜→作業 |
| NB50327 | 2026/09/21 | 敬老の日→休み |
| 全件 | 2026/11/06 | 平日→休み |

判定はこうなります。

| その日が | 詳細列 | 意味 |
|---|---|---|
| 日曜・お盆・年末年始（＝休み） | **日曜→作業** など | その日だけ稼働日として扱う |
| 祝日（＝もともと稼働日） | **敬老の日→休み** | その日だけ休みとして扱う |
| 平日 | **平日→休み** | その日だけ休みとして扱う |

> **祝日は稼働日です。** 祝日を休みにしたい物件は、ここに日付を書いてください。

つまり **その日の扱いが反転します。** 区分を選ぶ必要はありません。

#### 全物件にまとめて適用したいとき

契約番号に **`全件`** と入力すると、すべての物件に適用されます。
会社都合で稼働が止まる日などに使ってください。

#### 反映されるもの

例外日は **日祝の塗りつぶしと工期の計算の両方**に効きます。

```
例外なし                      基礎 09/01〜09/12
平日 09/08 を休みにする        基礎 09/01〜09/14  （+2日）
「全件」で 09/10・09/11 休工   基礎 09/01〜09/15  （+3日、全物件が同じだけ後ろへ）
```

入力後は **`ボタン_工程を計算する`** → **`ボタン_工程表に色を塗る`** を実行してください。
どちらも実行時に例外日を読み直します。

### 工程を作る（基礎・躯体）

`M_工程データ` は **1物件1行**で、工程が横に5列ずつ並びます。
同じ物件の基礎と躯体が横一列に見えるので、担当の重なりを目で追えます。

| A 契約番号 | B 邸名 | C 基礎開始日 | D 基礎調整 | E 基礎終了日 | F 色名 | G 備考 | H 躯体開始日 | I 躯体調整 | J 躯体終了日 | K 色名 | L 備考 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| NB50212 | 西田 貴紀邸 | 2026/09/01 | | | | | | | | | |

**入力するのは C列（基礎開始日）だけで足ります。**
空欄なら、工程表の **本着日**が開始日として使われます。

**業者は工程表シートに書いてあるものを読みます。**
お客様名の右が建設地、その右が **基礎業者**、さらに右が **躯体業者**です。
その業者名を `M_業者` で引いて色を決めるので、`M_工程データ` の色名は空欄で構いません。

**計算と色塗りは別のボタンに分かれています。** 順に実行してください。

#### 手順1 **`ボタン_工程を計算する`**（工程表には触りません）

1. 工程表からタイプ（例 `C2E42`）を読み、坪数と建物種類を取り出す
2. 工程表の業者欄を読み、`M_業者` で色を決める
3. 工期の式で **基礎**の稼働日数を計算し、終了日を確定する
4. **躯体開始日が空欄なら、基礎の終了日 + 4日（暦日）から自動で決める**
5. 同じ式で**躯体**の終了日を確定する
6. **同じ業者が2現場に重ならないよう、後の現場を後ろへずらす**

結果は `M_工程データ` に書き込まれます。**ここで内容を目で確認できます。**

#### 手順2 **`ボタン_工程表に色を塗る`**（計算はしません）

`M_工程データ` の 開始日・終了日・色名 をそのまま工程表に塗ります
（基礎は下2行、躯体は上1行）。塗る順番はこうです。

1. 前回の工程色を消す
2. 日祝を塗る
3. 工程の色を塗る（日祝の上に重なる）
4. **本着日を黒、お客様納期を青**で塗る

本着日と納期の塗り方は次のとおりです。

| | 色 | 塗る場所 |
|---|---|---|
| 本着日 | 黒 (0,0,0) | **基礎工事の下の1マスだけ** |
| お客様納期 | 青 (0,102,204) | 物件ブロックの上から**縦4マス** |

**本着日の列だけ、基礎の色帯は1行上へずらして塗ります。**
黒とぶつかって基礎の色が消えないようにするためです。

> 分かれているので、**計算結果を確認してから塗る**という進め方ができます。
> 色だけ塗り直したいときも、計算をやり直さずに済みます。

### 業者の順番はシートの上から

**1業者は同時に2現場へ入れません。** 割り振りはこうなります。

- 物件は **工程表の上にあるものから優先**されます
- 前の現場が終わった **翌営業日**から次の現場に入ります
- 次の現場の開始予定日が前の現場の完了より前なら、**開始日が後ろへずれます**
- 空いていても予定日より早くは始めません（前倒しはしません）

```
龍壱（基礎）の3物件            本着日      → 計算結果
  1件目（シートの上）          09/01        09/01〜09/14
  2件目                        09/04        09/15〜09/28  （後ろへずれる）
  3件目                        09/07        09/29〜10/12  （さらにずれる）
```

**優先順位を変えたいときは工程表の物件の並びを変えて、
`ボタン_物件を取り込む` をやり直してください。**

業者を変えたいときは、工程表の業者欄を書き換えて計算し直します。
このとき `M_工程データ` の色名が埋まっていると**そちらが優先される**ので、
色名を消してから実行してください。

### 空欄のところだけ埋まります

会社やお客様の都合で日程を人が決めることがあるため、
**すでに値が入っているセルには一切触りません。** 計算して書き込むのは空欄だけです。

| 列 | 空欄のとき | 入力してあるとき |
|---|---|---|
| 基礎開始日 | 本着日から決めて書き込む（本着日も空なら計画対象外） | **その日を使う** |
| 躯体開始日 | 基礎終了日 + 4日から自動で決めて書き込む | **その日を使う** |
| 終了日 | 工期の式で計算して書き込む | **その日を使う（計算しない）** |
| 調整 | 0 | 終了日を計算するときだけ使う（`+1` `-2` など） |
| 色名 | 工程表の業者名から引いて書き込む | **その色で固定（業者欄より優先）** |
| 備考 | — | マクロは読み書きしません |

```
1) 何も入力しない         基礎 09/01〜09/12(本着日から)  躯体 09/16〜09/19(自動)
2) そのまま再実行         何も変わらない
3) 基礎終了日を 09/25 に手入力（躯体はクリア）
                          基礎 09/01〜09/25(手入力を尊重)
                          躯体 09/29〜10/02(そこから引き直し)
4) 躯体開始日を 10/12 に固定
                          躯体 10/12〜10/16(開始日を尊重、終了日だけ計算)
```

### 日程がずれたとき（雨など）

計算し直したい行を選んで、**`ボタン_選択行の計算結果をクリア`** を実行します。

1. `M_工程データ` で対象の行を選択
2. **`ボタン_選択行の計算結果をクリア`**（終了日・色名・躯体開始日が消えます）
3. 基礎開始日を新しい日付に直す
4. **`ボタン_工程を計算する`** → **`ボタン_工程表に色を塗る`**

```
雨で3日ずれ → クリアして 09/04 に直す
  基礎 09/04〜09/16    躯体 09/22〜09/25
  （工期の日数は変わらない）
```

全物件をまとめてやり直したいときは **`ボタン_工程の計算結果をクリア`** を使ってください。

> **クリアせずに開始日だけ直すと、終了日は前のまま残ります。**
> 「入っている値は触らない」仕様のためです。必ずクリアしてから直してください。

> 1件だけクリアして計算し直すと、**その業者の後ろの現場はずれません。**
> 後続もまとめて引き直したいときは、その業者の物件をまとめて選んでクリアしてください。

### 手入力した開始日に業者が入れないとき

手入力の開始日は書き換えません。代わりに**重なっていることを知らせます。**

```
■ その日程では業者が入れません（1件）

  【基礎】新規 太郎邸  開始日 2026/09/07
    業者「黄」は 西田 貴紀邸 に入っています。
    → 2026/09/15 以降なら入れます

  手入力の開始日は書き換えていません。次のどれかで解消できます。
    ・上に出ている日まで開始日をずらす
    ・先に入っている物件の日程を動かす
    ・工程表の業者欄を別の業者に変える

  ※このままだと同じ業者が2現場に重なります。
```

**どの物件にふさがれているか**と、**いつから入れるか**が出ます。

### 色と業者の対応（初期値）

`M_業者` には工事店さま指定の色が入っています。

| 色名 | RGB | 工種 | 業者名 |
|---|---|---|---|
| 茶 | 153,51,0 | 躯体 | 雅建工 |
| 薄紫 | 204,153,255 | 躯体 | 丸岩 / KRK |
| 青 | 0,102,204 | 基礎 | 協栄 |
| 緑 | 51,153,102 | 基礎 | 加納 |
| 桃 | 255,0,255 | 基礎 | カサハラ |
| 薄橙 | 255,204,153 | 基礎 | 龍壱 |

日祝の黄緑は 153,204,0、お客様納期の青は 0,102,204（協栄と同じ色ですが、
塗る場所が違うので区別できます）。

色を直したいときは `M_業者` の R/G/B を書き換えてください。
**ただし `ボタン_初期セットアップ` を実行すると初期値に戻ります**
（H列の「版」が上がったときだけ作り直され、古い内容は `M_業者_旧1` に残ります）。

### 業者名が見つからないとき

工程表に書かれた業者名が `M_業者` に無いと、計算時に警告が出ます。

```
■ 警告:
  新規 太郎邸 [基礎] : 業者「田中組」が M_業者 にありません（工種基礎）
```

`M_業者` に行を足して、**色名・RGB・工種・業者名**を入れてください。
表記ゆれがある業者は、業者名の欄に `丸岩/KRK/丸岩KRK` のように `/` 区切りで並べれば
どの書き方でも引けます（前後・途中の空白は無視されます）。

### 工期の計算だけ確認したいとき

**`ボタン_工期の計算を確認`** にタイプを入力すると、解析結果と計算日数が出ます。

```
タイプ : C2E42
  建物種類 : C
  階数     : 2 階
  坪数     : 42 坪

基礎工事 : 11 稼働日
躯体工事 : 4 稼働日
```

> **現在の制約**：色帯は開始日から連続で塗られます。
> 実物の基礎は途中の養生で途切れますが、その入り方が未確定のため未対応です
> （→ 確認事項 Q4）。工期の合計日数は実測に基づいています。

### 工程の色だけ消したい

**`ボタン_工程の色をクリア`** を実行すると、工程表から `M_業者` に登録されている
色だけを消します。

| 消えるもの | 残るもの |
|---|---|
| 工程の色（基礎・躯体の業者色） | 日祝の黄緑 |
| 本着日の黒・納期の青（`M_業者` に同じ色があるため） | |
| | 手で塗った色（マクロが知らない色） |
| | `M_工程データ` の日付 |

日付は残るので **`ボタン_工程表に色を塗る`** で塗り直せます。
日程から作り直したい場合は、先に `ボタン_工程の計算結果をクリア` を実行してください。

> 元に戻す（Ctrl+Z）は効きません。実行前にファイルをコピーしておいてください。

### 業者がダブっていないか確認する

**`ボタン_業者の重複を確認`** を実行すると、
同じ色（＝同じ業者）が別の物件で同じ日に入っている箇所が一覧で出ます。

```
3 件の重複が見つかりました。

  2026/09/25  [躯体] 色[茶]  NB50212 と NB50327
  2026/09/26  [躯体] 色[茶]  NB50212 と NB50327
  2026/09/28  [躯体] 色[茶]  NB50212 と NB50327
```

順送りの計算では重複しませんが、開始日や色名を手で指定した場合の確認に使えます。

### セルの意味が分からなくなったとき

工程表上でセルを選択して **`ボタン_このセルは何`** を実行すると、
そのセルの日付（稼働日か、日曜・祝日・お盆等か）・物件・行の意味（躯体／基礎／モルタル 等）が表示されます。

## カレンダー（日付列）を書き換えたとき

**初期セットアップのやり直しは不要です。**

日付↔列の対応も物件ブロックの位置も、**実行のたびにシートから読み直しています。**
保存しているのはシート名とカレンダーの基準年だけで、列番号や行番号は保存していません。

7月分の列を削除した場合:

| 起きること | 影響 |
|---|---|
| 7月に塗っていた色も消える | Excelの列削除なので当然。8月以降は残ります |
| `M_工程データ` に7月の日程が残る | **エラーにならず、単に塗られません** |
| 物件ブロックの行位置が変わる | 毎回走査するので自動で追随します |

やり直しが必要なのは、**日付行が3行目でなくなる**か、
**日付エリアの開始列がQ列でなくなる**場合だけです。
これは初期設定ではなく `M00_Config.bas` の定数修正になります。

心配なときは **`ボタン_レイアウトを検証`** で、日付の範囲と物件件数を確認できます。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「Sub または Function が定義されていません」 | モジュールの入れ忘れ、または古いモジュールの残り。全部消してから6つ入れ直してください |
| 新しいボタンがマクロ一覧に出ない | `ボタン_〇〇` はすべて `M99_Menu.bas` にあります。M99 も入れ直してください |
| 「M_業者 / M_工程データ シートが古い形式です」 | `ボタン_初期セットアップ` を実行。古いシートは `_旧1` を付けて残ります |
| 例外日を入れたのに工期が変わらない | `ボタン_工程を計算する` を再実行してください。実行時に読み直します |
| 工程表の色だけ消したい | `ボタン_工程の色をクリア`（日付は残るので塗り直せます） |
| 開始日を直したのに終了日が変わらない | 「入っている値は触らない」仕様です。`ボタン_選択行の計算結果をクリア` を先に実行してください |
| 手入力した日程を守りたい | そのまま入れておけば守られます。計算されるのは空欄だけです |
| 何が足りないのか分からない | `ボタン_導入状態を確認` を実行してください |
| 「工程表シート「1」が見つかりません」 | 古い版のモジュールです。最新の `vba/sjis/` を入れ直してください |
| 「どのシートが工程表か分かりません」 | 工程表シートを開いて `ボタン_このシートを工程表に設定` を実行 |
| 別のシートが塗られてしまった | 対象シートを開いて `ボタン_このシートを工程表に設定` を実行し直す |
| 「物件ブロックが見つかりません」 | `ボタン_レイアウトを検証` を実行し、`M00_Config` の `ROW_BLOCK_1ST` / `COL_NAME` を確認 |
| 「3行目に日付が見つかりません」 | `ROW_DATE` / `COL_DATE_FIRST` が実際のシートとずれています |
| 塗る位置が1行ずれる | ブロック内オフセット（`OFS_KUTAI` 等）が現行シートと違う可能性。`ボタン_このセルは何` で確認 |
| 実行が遅い | 日付列が215列 × 物件30件 × 6行 = 約4万セルを走査します。10〜30秒程度かかります |
| 塗りすぎた／元に戻したい | `ボタン_日祝の塗りを全部消す` で日祝の黄緑だけ消せます（工程色は残ります） |
| 工程表の業者を変えたのに色が変わらない | `M_工程データ` の色名が優先されます。色名を消してから計算し直してください |
| 「業者が M_業者 にありません」 | `M_業者` に業者名を足すか、`丸岩/KRK` のように別名を `/` で並べてください |
| 「工程表に基礎業者が書かれていません」 | 工程表の業者欄が空か、`COL_KISO_VENDOR` の列がずれています |
| 祝日が休みになってしまう | 祝日は稼働日が既定です。休みにしたい日は `M_例外日` に登録してください |
| 本着日・納期が塗られない | その日付が工程表の表示期間の外にあります。`ボタン_レイアウトを検証` で読めているか確認 |
| 「タイプから工期を計算できません」 | 工程表のタイプ欄が空か、想定外の書式です。`ボタン_工期の計算を確認` で確かめてください |
| 工期が実感と違う | `M02_Masters.bas` の `TermDays` / `TypeCorrection` の値を直して、モジュールを入れ直してください |
| レイアウト検証の年が違う | `ボタン_カレンダーの年を設定` で先頭列の年を指定してください |
| 本着日・納期が塗られない | 年がずれている可能性があります。上の行を確認してください |
| 業者の色が指定と違う | `ボタン_初期セットアップ` を実行すると `M_業者` が現行の色で作り直されます（古い内容は `M_業者_旧1` に残ります） |
| 設定が消えた | ブックを保存せずに閉じた可能性があります。設定はブックの中に保存されます |

> **元に戻す（Ctrl+Z）はマクロ実行後には効きません。** 実行前にファイルをコピーしておいてください。
