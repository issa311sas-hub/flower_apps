# セットアップ手順

所要 15〜20分。Excel の操作だけで完結します。

## 前提

- Windows 版 Excel（VBA を使うため。Mac 版でも動きますが未検証）
- 現行の工程表ファイル（`.xls`）

## 1. マクロ有効ブックとして保存し直す

1. 現行の工程表を Excel で開く
2. **ファイル → 名前を付けて保存**
3. ファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」** に変更して保存

> `.xls` のままではマクロを保存できません。必ず `.xlsm` にしてください。
> 元ファイルは別名で残しておくことをおすすめします。

## 2. 開発タブを表示する

**ファイル → オプション → リボンのユーザー設定** で、右側の **「開発」** にチェック。

## 3. VBA モジュールを取り込む

> **重要1：モジュールは常に6つまとめて入れ替えてください。**
> VBA はプロジェクト全体をコンパイルするため、1つでも古いままだと
> 「Sub または Function が定義されていません」で止まります。
> 1ファイルだけ差し替える運用はできません。
>
> **重要2：必ず `vba/sjis/` の方を取り込んでください。**
> `vba/` 直下のファイルは UTF-8 です。VBE の「ファイルのインポート」は
> 日本語版 Windows では Shift-JIS として読むため、UTF-8 版を取り込むと
> マクロ名・シート名・判定文字列がすべて文字化けします。

1. **開発タブ → Visual Basic**（または `Alt + F11`）
2. 左のツリーで、対象のブック名を右クリック → **ファイルのインポート**
3. **`vba/sjis/`** フォルダの `.bas` を **6つすべて** インポートする

| ファイル | 役割 |
|---|---|
| `M00_Config.bas` | 座標定数・タイプ解析・共通ヘルパー |
| `M01_Holiday.bas` | 祝日・会社休業日の判定 |
| `M02_Masters.bas` | マスタシートの生成・工期の計算 |
| `M03_PaintHolidays.bas` | 日祝の塗りつぶし |
| `M05_Plan.bas` | 工程の自動生成（基礎・躯体）・重複チェック |
| `M99_Menu.bas` | ボタン用エントリポイント |

4. **参照設定を確認**：VBEのメニュー **ツール → 参照設定** で
   **Microsoft Scripting Runtime** にチェックが無くても動きます（遅延バインディングを使用）。特別な設定は不要です。

### 文字化けしてしまったときの復旧

`Alt + F8` のマクロ一覧に `繝懊ち繝ｳ_...` のような文字列が並んでいたら、
UTF-8 版を取り込んでしまっています。**実行せずに入れ直してください。**
マクロ名だけでなく、コード内のシート名 `"M_業者"` や判定文字列 `"非祝日扱い"` も
壊れているため、そのまま実行すると文字化けしたシートが作られます。

1. `Alt + F11` で VBE を開く
2. 左のツリーの **標準モジュール** から `M00_Config` 〜 `M99_Menu` を右クリック
3. **「M00_Config の解放」** を選び、「エクスポートしますか？」には **いいえ**
4. 全モジュールを削除したら、`vba/sjis/` から入れ直す

### 開発者向け：Shift-JIS 版の作り方

`vba/` を編集したら、以下で `vba/sjis/` を作り直します。

```bash
python tools/make_import_bas.py
```

CP932 で往復できない文字があるとエラーで止まるので、
文字化けしたまま気づかずコミットすることはありません。

## 4. 工程表シートを指定する

マクロは「どのシートが工程表か」を知る必要があります。
シート名はブックによって違う（`1` だったり `工程表実データ` だったり）ため、指定します。

1. **色を塗りたいシートを開く**（例：`検証用`）
2. `Alt + F8` → **`ボタン_このシートを工程表に設定`** を実行

`M_設定` シートが作られ、B1 にシート名が入ります。あとから B1 のプルダウンで切り替えられます。

> 検証用シートで試してから本番シートに移る、といった使い分けができます。
> 対象を変えるときは `M_設定` の B1 を選び直すか、対象シートを開いてこのボタンを再実行してください。

指定しなかった場合は、`1` という名前のシート → 開いているシート、の順で探します。

## 5. レイアウトを検証する（重要）

いきなり塗ると事故るので、まず座標が合っているかを確認します。

1. `Alt + F8` でマクロ一覧を開く
2. **`ボタン_レイアウトを検証`** を実行

以下のような内容が出れば正常です。

```
■ 対象シート : 検証用

■ 日付エリア
  日付の行     : 3 行目
  日付の列数   : 215 列
  先頭         : 17 列目 = 2026/07/01
  末尾         : 233 列目 = 2027/01/31

■ 物件ブロック
  検出件数     : 30 件
  先頭5件:
    5行目  岡﨑 毅邸  [RL50033]  V3F208
    ...
```

**日付や物件名が実際のシートと食い違う場合は、ここで止めてください。**
`M00_Config.bas` の定数（`ROW_DATE` / `COL_DATE_FIRST` / `ROW_BLOCK_1ST` / `COL_NAME`）を
実際のシートに合わせて直してから先に進みます。

## 6. マスタシートを作る

`Alt + F8` → **`ボタン_初期セットアップ`** を実行。

以下の5シートが追加されます。

| シート | 中身 |
|---|---|
| `M_設定` | 工程表シートの指定（手順4で作られていれば、そのまま使われます） |
| `M_業者` | 色と業者の対応表。色は実測値が入っています。業者名は分かる範囲で埋めてください |
| `M_例外日` | 例外日。契約番号と日付だけ入力すれば、扱いが反転します |
| `M_工期` | 工期の計算式と種類補正。過去46物件の実測から算出した値が入っています |
| `M_工程データ` | 色塗りの元データ。1物件1行で、工程が横に並びます |

## 7. 日祝を塗ってみる

`Alt + F8` → **`ボタン_日祝を塗る`** を実行。

日曜・祝日に加え、**お盆(8/13〜16)と年末年始(12/30〜1/3)** も非稼働日として黄緑で塗られます。
実行後にメッセージが出ます。

```
塗った   : 8,640 セル
消した   : 0 セル
見送った : 12 セル（工程色が入っていたため）
```

**「見送った」** は、すでに工程色が入っていて上書きしなかったセルです。
社内行事の色を日曜に載せている箇所などが該当します。一覧が表示されるので確認してください。

> 何度実行しても結果は同じです（塗り直しても増えません）。

## 8. ボタンを配置する（任意）

毎回 `Alt + F8` を押すのが面倒な場合。

1. **開発タブ → 挿入 → フォームコントロールのボタン**
2. 工程表の空いている場所にドラッグして配置
3. マクロの割り当てダイアログで、以下から選ぶ

| ボタン名の例 | 割り当てるマクロ |
|---|---|
| 日祝を塗る | `ボタン_日祝を塗る` |
| 工程を作る | `ボタン_工程を作る` |
| 選択行の計算結果をクリア | `ボタン_選択行の計算結果をクリア` |
| 工程の色をクリア | `ボタン_工程の色をクリア` |
| 業者の重複を確認 | `ボタン_業者の重複を確認` |
| 導入状態を確認 | `ボタン_導入状態を確認` |
| このセルは何？ | `ボタン_このセルは何` |

## 使い方

### 例外日を設定する（祝日に稼働する／平日に休む）

`M_例外日` シートに **契約番号と日付の2列だけ**入力します。
「詳細」列はマクロが日付から判定して書き込むので、触らなくて構いません。

| A 契約番号 | B 日付 | C 詳細（自動） |
|---|---|---|
| NB50212 | 2026/09/21 | 日祝→作業 |
| NB50327 | 2026/10/15 | 平日→休み |
| 全件 | 2026/11/06 | 平日→休み |

判定はこうなります。

| その日が | 詳細列 | 意味 |
|---|---|---|
| 日祝（日曜・祝日・お盆・年末年始） | **日祝→作業** | その日だけ稼働日として扱う |
| それ以外（平日） | **平日→休み** | その日だけ休みとして扱う |

つまり **その日の扱いが反転します。** 区分を選ぶ必要はありません。

#### 全物件にまとめて適用したいとき

契約番号に **`全件`** と入力すると、すべての物件に適用されます。
会社都合で稼働が止まる日などに使ってください。

#### 反映されるもの

例外日は **日祝の塗りつぶしと工期の計算の両方**に効きます。

```
例外なし                      基礎 09/01〜09/12
平日 09/08 を休みにする        基礎 09/01〜09/14  （+2日）
「全件」で 09/10・09/11 休工   基礎 09/01〜09/15  （+3日、全物件が同じだけ後ろへ）
```

入力後は **`ボタン_工程を作る`** と **`ボタン_日祝を塗る`** を実行してください。
どちらも実行時に例外日を読み直します。

### 工程を作る（基礎・躯体）

`M_工程データ` は **1物件1行**で、工程が横に5列ずつ並びます。
同じ物件の基礎と躯体が横一列に見えるので、担当の重なりを目で追えます。

| A 契約番号 | B 邸名 | C 基礎開始日 | D 基礎調整 | E 基礎終了日 | F 色名 | G 備考 | H 躯体開始日 | I 躯体調整 | J 躯体終了日 | K 色名 | L 備考 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| NB50212 | 西田 貴紀邸 | 2026/09/01 | | | | | | | | | |

**入力するのは C列（基礎開始日）だけで足ります。**

**`ボタン_工程を作る`** を実行すると、以下が自動で行われます。

1. 工程表からタイプ（例 `C2E42`）を読み、坪数と建物種類を取り出す
2. `M_工期` の式で **基礎**の稼働日数を計算し、終了日を確定する
3. **躯体開始日が空欄なら、基礎の終了日 + 4日（暦日）から自動で決める**
4. 同じ式で**躯体**の終了日を確定する
5. 工種ごとに、**同じ業者が同じ日に2現場へ入らないよう業者を割り当てる**
6. 工程表に色を塗る（基礎は下2行、躯体は上1行）

### 空欄のところだけ埋まります

会社やお客様の都合で日程を人が決めることがあるため、
**すでに値が入っているセルには一切触りません。** 計算して書き込むのは空欄だけです。

| 列 | 空欄のとき | 入力してあるとき |
|---|---|---|
| 基礎開始日 | その物件は計画対象外 | **その日を使う** |
| 躯体開始日 | 基礎終了日 + 4日から自動で決めて書き込む | **その日を使う** |
| 終了日 | 工期の式で計算して書き込む | **その日を使う（計算しない）** |
| 調整 | 0 | 終了日を計算するときだけ使う（`+1` `-2` など） |
| 色名 | 空いている業者を割り当てて書き込む | **その業者で固定** |
| 備考 | — | マクロは読み書きしません |

手入力した日程も「業者の空き」として数えるので、**自動割り当てが人の予定と被りません。**

```
1) 基礎開始日だけ入力     基礎 09/01〜09/12(計算)  躯体 09/16〜09/19(自動)
2) そのまま再実行         何も変わらない
3) 基礎終了日を 09/25 に手入力（躯体はクリア）
                          基礎 09/01〜09/25(手入力を尊重)
                          躯体 09/29〜10/02(そこから引き直し)
4) 躯体開始日を 10/12 に固定
                          躯体 10/12〜10/16(開始日を尊重、終了日だけ計算)
```

### 日程がずれたとき（雨など）

計算し直したい行を選んで、**`ボタン_選択行の計算結果をクリア`** を実行します。

1. `M_工程データ` で対象の行を選択
2. **`ボタン_選択行の計算結果をクリア`**（終了日・色名・躯体開始日が消えます）
3. 基礎開始日を新しい日付に直す
4. **`ボタン_工程を作る`**

```
雨で3日ずれ → クリアして 09/04 に直す
  基礎 09/04〜09/16    躯体 09/22〜09/25
  （工期の日数は変わらない）
```

全物件をまとめてやり直したいときは **`ボタン_工程の計算結果をクリア`** を使ってください。

> **クリアせずに開始日だけ直すと、終了日は前のまま残ります。**
> 「入っている値は触らない」仕様のためです。必ずクリアしてから直してください。

### 業者が足りなくて割り当てできないとき

その期間に空いている業者が1社もないと、**理由と対処法が表示されます。**

```
■ 割り当てできませんでした（1件）

  【基礎】新規 太郎邸  09/07～09/18（11稼働日）
    この期間は4業者すべてがふさがっています。
      青   … 09/07 から 西田 貴紀邸 が使用中
      赤桃 … 09/07 から 井上 大邸 が使用中
      緑   … 09/07 から 高橋 隆太邸 が使用中
      桃   … 09/07 から 水野 海結邸 が使用中
    → 2026/09/14 から着手すれば「青」が空きます

  この日程では業者が足りません。次のどれかで解消できます。
    ・上に出ている日まで開始日をずらす
    ・先に入っている物件の日程を動かす
    ・M_業者 に業者を追加する

  ※この工程は終了日も色名も空欄のままで、工程表にも塗られていません。
```

**どの業者が誰にふさがれているか**と、**最短でいつから着手できるか**が出ます。
表示された日まで開始日をずらせば、そのまま割り当てられます。

割り当てできなかった工程は **終了日も色名も空欄のまま**残り、工程表にも塗られません。
数字だけ入って中身が無い、という状態にはなりません。

> 躯体の業者は初期状態で **茶・薄紫の2チームだけ**です。
> 同時期に3件以上の躯体工事が重なると、この表示が出ます。

### 工期の計算だけ確認したいとき

**`ボタン_工期の計算を確認`** にタイプを入力すると、解析結果と計算日数が出ます。

```
タイプ : C2E42
  建物種類 : C
  階数     : 2 階
  坪数     : 42 坪

基礎工事 : 11 稼働日
躯体工事 : 4 稼働日
```

> **現在の制約**：色帯は開始日から連続で塗られます。
> 実物の基礎は途中の養生で途切れますが、その入り方が未確定のため未対応です
> （→ 確認事項 Q4）。工期の合計日数は実測に基づいています。

### 工程の色だけ消したい

**`ボタン_工程の色をクリア`** を実行すると、工程表から `M_業者` に登録されている
色だけを消します。

| 消えるもの | 残るもの |
|---|---|
| 工程の色（基礎・躯体の業者色） | 日祝の黄緑 |
| | 手で塗った色（マクロが知らない色） |
| | `M_工程データ` の日付 |

日付は残るので **`ボタン_工程を作る`** で塗り直せます。
日程から作り直したい場合は、先に `ボタン_工程の計算結果をクリア` を実行してください。

> 元に戻す（Ctrl+Z）は効きません。実行前にファイルをコピーしておいてください。

### 業者がダブっていないか確認する

**`ボタン_業者の重複を確認`** を実行すると、
同じ色（＝同じ業者）が別の物件で同じ日に入っている箇所が一覧で出ます。

```
3 件の重複が見つかりました。

  2026/09/25  [躯体] 色[茶]  NB50212 と NB50327
  2026/09/26  [躯体] 色[茶]  NB50212 と NB50327
  2026/09/28  [躯体] 色[茶]  NB50212 と NB50327
```

自動割り当てを使っていれば重複は起きませんが、色名を手で指定した場合の確認に使えます。

### セルの意味が分からなくなったとき

工程表上でセルを選択して **`ボタン_このセルは何`** を実行すると、
そのセルの日付（稼働日か、日曜・祝日・お盆等か）・物件・行の意味（躯体／基礎／モルタル 等）が表示されます。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「Sub または Function が定義されていません」 | モジュールの入れ忘れ、または古いモジュールの残り。全部消してから6つ入れ直してください |
| 新しいボタンがマクロ一覧に出ない | `ボタン_〇〇` はすべて `M99_Menu.bas` にあります。M99 も入れ直してください |
| 「M_工期 / M_工程データ シートが古い形式です」 | `ボタン_初期セットアップ` を実行。古いシートは `_旧1` を付けて残ります |
| 例外日を入れたのに工期が変わらない | `ボタン_工程を作る` を再実行してください。実行時に読み直します |
| 工程表の色だけ消したい | `ボタン_工程の色をクリア`（日付は残るので塗り直せます） |
| 開始日を直したのに終了日が変わらない | 「入っている値は触らない」仕様です。`ボタン_選択行の計算結果をクリア` を先に実行してください |
| 手入力した日程を守りたい | そのまま入れておけば守られます。計算されるのは空欄だけです |
| 何が足りないのか分からない | `ボタン_導入状態を確認` を実行してください |
| 「工程表シート「1」が見つかりません」 | 古い版のモジュールです。最新の `vba/sjis/` を入れ直してください |
| 「どのシートが工程表か分かりません」 | 工程表シートを開いて `ボタン_このシートを工程表に設定` を実行 |
| 別のシートが塗られてしまった | `M_設定` の B1 が意図したシートになっているか確認 |
| 「物件ブロックが見つかりません」 | `ボタン_レイアウトを検証` を実行し、`M00_Config` の `ROW_BLOCK_1ST` / `COL_NAME` を確認 |
| 「3行目に日付が見つかりません」 | `ROW_DATE` / `COL_DATE_FIRST` が実際のシートとずれています |
| 塗る位置が1行ずれる | ブロック内オフセット（`OFS_KUTAI` 等）が現行シートと違う可能性。`ボタン_このセルは何` で確認 |
| 実行が遅い | 日付列が215列 × 物件30件 × 6行 = 約4万セルを走査します。10〜30秒程度かかります |
| 塗りすぎた／元に戻したい | `ボタン_日祝の塗りを全部消す` で日祝の黄緑だけ消せます（工程色は残ります） |
| 「タイプから工期を計算できません」 | 工程表のタイプ欄が空か、想定外の書式です。`ボタン_工期の計算を確認` で確かめてください |
| 工期が実感と違う | `M_工期` シートの基準日数・坪係数・種類補正を直せば反映されます（コード修正不要） |

> **元に戻す（Ctrl+Z）はマクロ実行後には効きません。** 実行前にファイルをコピーしておいてください。
