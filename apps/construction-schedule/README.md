# construction-schedule

ホームメーカー工程表（ローテーション表）作成の自動化マクロ。

## 概要

工事店が手作業で作成している Excel の工程表について、

- 必要最低限の情報入力から工程表の大枠を自動生成する
- 工事日程がずれたら、後続工程と業者の重複を自動で調整する

ことを目的とする。工程は**セルの色塗り**で表現されており、ここを間違えられないため、
色塗りの自動化が本題となる。

## 現状の課題

- 工程表は工事店が手作業で作成し、イベント情報を別セルからコピー＆ペーストしている
- 人的ミスが起こりやすい
- ある業者の日程が1日ずれると後続が連鎖的にずれるが、その調整も手作業
- 暗黙知（担当者の感覚）でルールが決まっており、明文化されていない

## 技術スタック

- Excel VBA（現行の `.xls` をそのまま `.xlsm` にして使う）
- Python + xlrd（過去データの解析ツール。開発時のみ使用）

**見た目（フォーマット）は現行のまま変更しない。**
業者・日程データは別シートで管理し、それを参照して工程表に色を反映する方式をとる。

  04-duration-model.md         ← タイプから工期を計算するモデル

  M00_Config.bas               ← 座標定数と共通ヘルパー
  M01_Holiday.bas              ← 祝日判定（計算で判定。外部データ不要）
  M02_Masters.bas              ← マスタシートの生成
  M03_PaintHolidays.bas        ← 日祝の自動塗りつぶし
  M05_Plan.bas                 ← 工程の自動生成（基礎・躯体）・業者重複チェック
  M99_Menu.bas                 ← ボタン用エントリポイント
  sjis/                        ← Shift-JIS。Excel に取り込むのはこちら（自動生成）

  analyze_chart.py             ← 過去の工程表を解析して工期を実測する
  make_import_bas.py           ← vba/ から vba/sjis/ を生成する
archive/                       ← 版ごとの保管（README.md に一覧と復元手順）
  2026-08-11/v1〜v15/

> **Excel に取り込むときは `vba/sjis/` を使ってください。**
> VBE の「ファイルのインポート」は日本語版 Windows では Shift-JIS として
> 読むため、UTF-8 の `vba/` を取り込むと日本語がすべて文字化けします。
> `vba/` を編集したら `python tools/make_import_bas.py` で作り直します。

## 開発フェーズ

クリティカル工程は7段階あり、**1つずつ順に実装していく**方針。

| # | 工程 | 状況 |
|---|---|---|
| 1 | 基礎工事 | **実装済み** |
| 2 | 躯体工事 | **実装済み** |
| 3 | モルタル工事 | 未 |
| 4 | 防水工事 | 未 |
| 5 | 断熱工事 | 未 |
| 6 | 木工事 | 未 |
| 7 | 仕上げ工事 | 未 |

### Phase 1 — 実装済み

- [x] 日曜・祝日の自動判定と塗りつぶし（**休みは日曜のみ。祝日は稼働日だが色は塗る**）
- [x] 会社休業日（お盆 8/13-16・年末年始 12/30-1/3）
- [x] 物件ごとの例外日（日付から扱いを自動反転。「全件」指定で全物件に適用）
- [x] 例外日を**塗りつぶしと工期計算の両方**に反映
- [x] マスタシートの設計と生成（業者・例外日・工程データの3枚だけ）
- [x] 設定と工期はマクロ内に保持（利用者が触るシートを増やさない）
- [x] 工程表シートの指定（検証用と本番の切り替え）
- [x] タイプコードから建物種類・階数・坪数を解析
- [x] 種類と坪数から工期を計算するモデル
- [x] **基礎・躯体の工程自動生成**（計算と色塗りは別ボタン）
- [x] 日祝の塗りつぶしを色塗り処理と初期セットアップに取り込み
- [x] 躯体開始日を基礎終了日から自動決定
- [x] M_工程データ を1物件1行の横並びに（同じ物件の工程が横に並ぶ）
- [x] **工程表に書かれた業者を読んで色を決める**（基礎業者・躯体業者の欄）
- [x] **業者の順送り**（シートの上から優先。前の現場の翌営業日から次の現場へ）
- [x] **本着日（黒1マス・基礎の色は1行上へ退避）・お客様納期（青・縦4マス）**
- [x] **カレンダーの年がずれている表の補正**（先頭列の年を指定して振り直す）
- [x] 同一業者（＝同一色）の重複稼働チェック
- [x] 手入力の開始日が業者の前の現場と重なるとき、入れる日を表示
- [x] **手入力（黒字）は書き換えず、マクロが入れた値（青字）は毎回決め直す**
- [x] **選択行と、同じ業者を使う後続の物件だけ再計算**（調整をあとから入れる用）
- [x] **色を消してから塗り直す**（実務用。塗る／消すの単独ボタンも残してある）
- [x] 選択行だけ計算結果をクリア（雨によるズレの引き直し用）
- [x] レイアウト検証機能（座標のずれを事前に検出する）

## 過去データについて

解析に使ったのは 2026年4月〜8月版の工程表7ファイル（各ファイル7ヶ月分を収録）。
うち、契約着工日から躯体完了までが完全に収まっている **46物件** を工期の実測対象とした。

過去データそのものより、**言語化されていないルールの明文化**が主目的。
新しい過去データが手に入ったら `tools/analyze_chart.py` で同じ集計をやり直せる。

```bash
pip install xlrd==2.0.2
python tools/analyze_chart.py <工程表が入っているディレクトリ>
```
