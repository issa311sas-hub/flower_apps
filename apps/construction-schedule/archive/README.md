# archive

VBA モジュールの変更履歴を日付・バージョン別に保管するフォルダ。

```
archive/
  2026-08-11/
    v1/                    ← Phase 1 実装
      CHANGELOG.md
      M00_Config.bas
      M01_Holiday.bas
      ...
    v2/                    ← 同日の2回目の変更
      ...
```

## ルール

- 日付は変更を行った日（YYYY-MM-DD）
- 同日に複数回変更がある場合は v1, v2, ... と番号を振る
- 各バージョンに `CHANGELOG.md` を置き、**変更理由・変更内容・既知の問題**を記録する
- 保管するのは UTF-8 の `.bas`（GitHub 上で読め、版どうしの差分も取れる）
- `sjis/` は生成物なので保管しない。取り込みたいときは下記の手順で作る

## 過去の版を Excel に戻す手順

1. 戻したい版のフォルダを指定して、取り込み用の Shift-JIS 版を作る

   ```bash
   python tools/make_import_bas.py archive/2026-08-11/v5
   ```

   `archive/2026-08-11/v5/sjis/` に CP932 の `.bas` が書き出されます。

2. `Alt + F11` で VBE を開き、**標準モジュールをすべて解放**（エクスポートは「いいえ」）
3. 手順1で作った `sjis/` フォルダから **全モジュールをインポート**
4. `ボタン_初期セットアップ` を実行

> **モジュールは常に全部まとめて入れ替えてください。**
> VBA はプロジェクト全体をコンパイルするため、1つでも版が食い違うと
> 「Sub または Function が定義されていません」で止まります。

## 新しい版を追加するとき

```bash
# 1. vba/ を編集して動作確認まで済ませる
# 2. 新しい版のフォルダを作って現行をコピー
mkdir -p archive/$(date +%Y-%m-%d)/vN
cp vba/*.bas archive/$(date +%Y-%m-%d)/vN/

# 3. CHANGELOG.md を書く（変更理由・変更内容・既知の問題）
# 4. この README の一覧表に行を足す
```
