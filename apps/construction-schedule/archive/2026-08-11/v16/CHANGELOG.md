# v16 — 本着日が塗れない件の対策・イベント名の書き込み

## 変更した理由

1. **本着日の黒が塗られない。** 本来は基礎工事の先頭の日が黒いはず。
2. 工程表は色だけでなく**イベント名を文字でも書く**。
   M0〜M5 / 家具搬入 / CL / クリーンハウス / 2W を入力するボタンが欲しい。

## 変更内容

### 本着日・お客様納期をラベルから探すようにした（M00_Config）

これまでは「ブロック先頭 +3 行目・11列目」と決め打ちで読んでいた。
ブックによって1行・1列ずれていると空になり、黒が塗られない。

`FindBlockDate` を追加し、**ラベル（「本着」「納期」）を手がかりに探す**ようにした。

1. ブロックの6行 × 左側の列（`COL_INFO_FIRST`〜`COL_INFO_LAST` = 8〜16列）から
   ラベルの入ったセルを探す
2. そのセル自身 → 下 → 右 → 右下 → 2つ下 の順に日付を探す
3. 見つからなければ、これまでどおり決め打ちの座標で読む

### 塗れなかった理由が分かるようにした（M05_Plan）

`ボタン_工程表を塗り直す` の結果に、本着日・納期の内訳を出すようにした。

```
本着日（黒） : 28 件 / 日付なし 2 件
お客様納期（青） : 27 件 / 表示期間外 3 件
    西田 貴紀邸 2027/03/15
```

- **日付なし** … ラベルも決め打ちの座標も空だった（座標の問題）
- **表示期間外** … 日付は読めたが、工程表のカレンダーにその日が無い

### イベント名の書き込み（M06_Events を新設）

**`ボタン_イベントを入力`** … 工程表の上で対象の物件の行にカーソルを置いて実行。
10個のイベントの日付を順に聞き、決まった行・書式で書き込む。

| イベント | 位置（物件の6行のなかで） | 文字色 | 向き | その他 |
|---|---|---|---|---|
| M0 / M1 | 上から6マス目（+5） | 黒 | 横書き | |
| M2 / M3 / M4 / M5 | 上から2マス目（+1） | 黒 | 横書き | |
| 家具搬入 | 上から2マス目 | 赤 | 縦書き | |
| CL | 上から2マス目 | 赤 | 縦書き | |
| クリーンハウス | 上から2マス目 | 黒 | 縦書き | |
| 2W | 上から2マス目 | 赤 | 横書き | **塗りつぶしを消す** |

- 物件はカーソルの行から判定する（邸名の行から6行がその物件）
- 空欄のまま OK で変更なし、`-` でそのイベントを消す、キャンセルで中止
- 書き込む前に確認画面を出す
- 同じイベントを入れ直すと、前に書いた場所を消してから新しい場所に書く
- 日付が工程表の表示期間の外なら、書き込まずに知らせる

**`ボタン_イベントを一覧表示`** … その物件のイベントと日付を一覧で見る。
**`ボタン_イベントをクリア`** … その物件のイベント文字をすべて消す。

「2W」の塗りつぶし無しは、色を塗り直しても保たれる（`ApplyEventFills`）。
日祝や工程の色を塗ったあとに、2W のセルの塗りつぶしを消し直している。

### モジュールが7つになった

`M06_Events.bas` を追加した。**取り込むときは7モジュールすべてを入れ替えること。**

## 実機で確認してほしいこと

1. `ボタン_工程表を塗り直す` の結果に出る「本着日（黒）」の件数
   - 「日付なし」が多い → ラベルの探索範囲（`COL_INFO_FIRST`〜`COL_INFO_LAST`）を広げる
   - 「表示期間外」が多い → カレンダーの年か、本着日の値そのものを確認
2. `ボタン_イベントを入力` で書かれる位置・文字色・向き

## 判断が要った点

- 依頼では「9つ」とあったが、挙げられていたのは
  M0〜M5（6個）+ 家具搬入 + CL + クリーンハウス + 2W の **10個**。10個で実装した。
- 「上から2マス目」をブロック先頭 +1（`OFS_KUTAI_SUB`）、
  「上から6マス目」を +5（`OFS_KISO_SUB`）と解釈した。
  実データでも単発イベントはこの2行に書かれている。

## 既知の問題

- ポップアップは10回の入力ダイアログを順に出す形。
  VBA のユーザーフォームは `.bas` だけでは配れないため、この方式にした。
  1画面で全部入れたい場合は別の作りが必要。
- イベント名は文字列の完全一致で探す。セル内に他の文字も入っていると、
  「同じイベントが別の日にある」と見なされず、消し忘れが残る。
