# v13 — 業者はシートで決まっている・祝日は稼働日

## 変更した理由

依頼者とのミーティングで、これまでの想定と実態が違うことが分かった。

1. **業者はランダムに割り当てるものではない。** 工程表のお客様名の右（建設地の右2列）に
   基礎業者・躯体業者が書かれており、それが色そのものを表している。
2. **祝日は作業がある。** 休みなのは日曜と会社休業日（お盆・年末年始）だけ。
   ただし工程表では日も祝も確認したいので、色は塗る。
3. お客様名の2つ下あたりに **本着日・お客様納期** が書いてあり、
   これを工程表に縦に塗って見えるようにしたい。

## 変更内容

### 業者はシートから読む（M00_Config / M05_Plan / M02_Masters）

- `FindBlocks` が1物件につき 8 要素を返すようになった
  （行 / 邸名 / 契約番号 / タイプ / 基礎業者 / 躯体業者 / 本着日 / お客様納期）
- 業者名 → 色名 は `M_業者` の「業者名」で引く。
  表記ゆれがある業者は `丸岩/KRK/丸岩KRK` のように `/` 区切りで並べられる。
  突き合わせは前後・途中の空白を落として行う。
- `M_業者` の初期値に、過去データから実測した業者名を入れた。

  | 色名 | 工種 | 業者名 |
  |---|---|---|
  | 茶 | 躯体 | 雅建工 |
  | 薄紫 | 躯体 | 丸岩 / KRK |
  | 青 | 基礎 | 協栄 |
  | 緑 | 基礎 | 加納 |
  | 桃 | 基礎 | カサハラ |
  | 黄 | 基礎 | 龍壱 |

- **空いている業者を探す仕組み（自動割り当て）は廃止した。**
  `FindFreeVendor` / `MarkOccupied` / `BlockingVendors` / `EarliestStart` /
  `SortPlanByStart` / `CountWorkDaysFor` を削除。

### 業者の順送り（M05_Plan）

- 物件はシートの**上から順**に処理する。これがそのまま優先順位になる。
  順番を変えたいときは工程表の並びを変えて「物件を取り込む」をやり直す。
- 1業者は同時に2現場へ入れない。前の現場が終わった**翌営業日**から次の現場に入る。
- 次の現場の開始予定日が前の現場の完了より前なら、**開始日を後ろへずらす**。
  空いていても予定日より早くは始めない（前倒しはしない）。
- 開始日が手入力されている行は書き換えない。重なるときは
  「その日程では業者が入れません」として、ふさいでいる物件と入れる日を表示する。
- 基礎の開始日が空欄のときは **本着日** を開始日に使う。

### 祝日は稼働日（M01_Holiday / M03_PaintHolidays）

- `IsNonWorkingDay` … 日曜 と 会社休業日 のみ。祝日は稼働日。
- `IsPaintDay` … 日曜 / 祝日 / 会社休業日。工程表で黄緑に塗る日。
- `IsPaintDayFor` … 上記に加え、例外日で休みにした平日も塗る。
- **塗った黄緑を剥がす処理を廃止した。** 工事がある日は工程色が上書きする。
- `M_例外日` の「詳細」の書き方を新ルールに合わせた。
  - 日曜・お盆・年末年始 → `日曜→作業` のように、休みの理由を添えて反転
  - 祝日（＝稼働日）     → `海の日→休み`
  - 平日                 → `平日→休み`
- `DayNote` を追加（`海の日（祝日・稼働日）` のような表示用の文字列）。

### 本着日・お客様納期を塗る（M00_Config / M05_Plan）

- 本着日は黒 RGB(0,0,0)、お客様納期は青 RGB(0,102,204)。
- 物件ブロックの先頭から縦 4 マス（`MARK_ROWS` / `MARK_OFS_FIRST` で調整できる）。
- 工程色を塗ったあとに載せるので、工事に隠れない。

### 色を塗る順番（M05_Plan）

1. 前回の工程色を消す
2. 日祝を塗る
3. 工程の色を塗る（日祝の上に重なる）
4. 本着日・お客様納期を塗る

### レイアウト検証（M99_Menu）

先頭5件について、基礎業者・躯体業者・本着日・納期も表示するようにした。
新しく読むようになった列が正しく取れているか、実機で確認するため。

## 実機で確認してほしいこと

- 「ボタン_レイアウトを検証」で、基礎業者・躯体業者・本着日・納期が正しく出るか
  （出ない場合は `M00_Config` の `COL_KISO_VENDOR` / `COL_KUTAI_VENDOR` /
  `COL_HONCHAKU` / `COL_NOUKI` / `ROW_OFS_DATES` を実際の列に合わせる）
- 工程表に書かれている業者名が `M_業者` の業者名と一致するか
  （一致しないものは計算時に警告に出る）

## 判断が要った点（確認したい）

| 項目 | 採用した想定 |
|---|---|
| お盆・年末年始 | 非稼働のまま（会社休業日のため） |
| 基礎の開始日 | 開始日が空欄なら本着日を使う |
| 業者の順送り | 遅らせるだけ、前倒ししない |
| 本着日・納期を塗る位置 | 物件ブロックの上から4マス |

本着日・納期の縦4マスは、物件ブロック（6行）のどこに載せるか指定が無かったため
上から4マスにした。実データでは契約着工日の黒は最下段（+5）にあるので、
そちらに合わせたい場合は `MARK_OFS_FIRST` を 2 にする。

## 既知の問題

- 色名を手入力していると、そちらが業者名より優先される。
  シートの業者を変えたのに色が変わらない場合は、`M_工程データ` の色名を消す。
- 業者の稼働は基礎・躯体それぞれ独立に見ている。
  1業者が基礎と躯体の両方を持つ運用には対応していない。
