# v9 - 2026-08-11 例外日を工期計算にも反映・全件指定・色クリア

## 変更理由
v8 までの例外日は **日祝の塗りつぶしにしか効いておらず、工期の計算には
반映されていなかった**。祝日稼働を設定しても終了日がずれたままになる、
致命的な不整合だった。あわせて入力の手間と運用上の要望に対応する。

## 変更内容

### 例外日を工期計算に反映（最重要）
非稼働日の判定を物件ごとに行う関数を M01_Holiday に追加した。

- `IsNonWorkingDayFor(契約番号, 日付)` … 例外があれば通常判定を反転する
- `AddWorkingDaysFor(契約番号, 日付, 日数)` … 物件ごとに稼働日を進める

M05_Plan の日数計算・塗り・業者の空き判定をすべてこちらに通した。
M03_PaintHolidays も同じ判定を使うようにして、塗りと計算の食い違いを無くした。

### M_例外日 を3列に（入力は2列だけ）
```
契約番号 | 日付 | 詳細（自動）
```
区分を選ばせるのをやめ、**日付から自動で判定**するようにした。

| その日が | 詳細列 | 扱い |
|---|---|---|
| 日祝（日曜・祝日・お盆・年末年始） | 日祝→作業 | 稼働日として扱う |
| それ以外（平日） | 平日→休み | 休みとして扱う |

旧形式（区分・備考の4列）が残っていたら `M_例外日_旧1` に退避して作り直す。

### 「全件」指定
契約番号に `全件` と書くと全物件に適用される。会社都合の休工に使う。

### 計算済みの行は上書きしない
終了日が計算結果と一致し、色名も入っている行は「前回と同じ」と判定して
シートも工程表も触らない。実行結果に件数を出す。
1件だけ直して再実行しても、他の物件の業者割り当ては変わらない。

### ボタン_工程の色をクリア（新規）
工程表から `M_業者` に登録された色だけを消す。日祝の黄緑と手で塗った色は残る。
`M_工程データ` の日付は消えないので「工程を作る」で塗り直せる。
v7 で色塗りを「工程を作る」に統合した際に単独機能が無くなっていたため復活させた。

## 検証
```
例外なし                       基礎 09/01～09/12
平日 09/08 を休みにする         基礎 09/01～09/14  （+2日）
敬老の日 09/21 を稼働にする      詳細列に「日祝→作業」
「全件」で 09/10・09/11 休工    全3物件が 09/01～09/15（+3日）
個別指定                       指定した物件だけ延び、他物件は変わらない
```

## 取り込み時の注意
