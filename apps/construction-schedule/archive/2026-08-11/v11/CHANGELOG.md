# v11 - 2026-08-11 割り当て不可の理由と最短着手日を表示する

## 変更理由
業者が全社ふさがっていて割り当てられない場合、v10 までは物件名と期間を
並べるだけだった。「なぜ無理なのか」「いつなら入れるのか」が分からず、
担当者が自分で工程表を追って調べる必要があった。

## 変更内容

### ふさいでいる相手を表示
業者の占有情報に契約番号を持たせ（`MarkOccupied`）、
各業者が「いつから」「どの物件に」使われているかを出せるようにした。

### 最短着手日を計算
`EarliestStart` を追加。稼働日数を保ったまま開始日を1日ずつ後ろへずらし、
どれか1社が期間中ずっと空く最初の日を探す（最大1年先まで）。

### 表示例
```
■ 割り当てできませんでした（1件）

  【基礎】新規 太郎邸  09/07～09/18（11稼働日）
    この期間は4業者すべてがふさがっています。
      青   … 09/07 から 西田 貴紀邸 が使用中
      赤桃 … 09/07 から 井上 大邸 が使用中
      緑   … 09/07 から 高橋 隆太邸 が使用中
      桃   … 09/07 から 水野 海結邸 が使用中
    → 2026/09/14 から着手すれば「青」が空きます

  この日程では業者が足りません。次のどれかで解消できます。
    ・上に出ている日まで開始日をずらす
    ・先に入っている物件の日程を動かす
    ・M_業者 に業者を追加する

  ※この工程は終了日も色名も空欄のままで、工程表にも塗られていません。
```

ダイアログのタイトルも「工程を作る － 割り当てできない工程があります」に変えた。

## 設計上の注意
割り当てできなかった工程は、終了日も色名も**空欄のまま残す**。
v10 の「空欄のところだけ埋める」方針と揃えており、
日付だけ入って業者が無い中途半端な状態にはならない。
開始日をずらして再実行すれば、そのまま埋まる。

## 検証
基礎4業者を 09/01〜09/04 起点で埋めた状態に 09/07 開始の物件を追加し、
全社ふさがりを検出して 09/14 から「青」が空くことを算出できるのを確認した。
