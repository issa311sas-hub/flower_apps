# v14 — 実機で出た指摘の反映（年ずれ・本着日・シート整理・色の指定）

## 変更した理由

v13 を実機で動かして出た指摘に対応した。

1. レイアウト検証で **2026年のカレンダーが2025年と判定される**
2. 本着日の黒は縦4マスではなく、**基礎工事の下1マスだけ**。
   そのマスに入るはずだった基礎の色は**1行上へずらす**
3. `M_設定` と `M_工期` は利用者が触らないので、**シートとして出したくない**
4. 色の RGB が実際と少し違う

## 変更内容

### カレンダーの年を指定できるようにした（M00_Config / M99_Menu）

前年の表を作り替えて使っていると、日付セルに入っている「年」が
実際とずれることがある。**`ボタン_カレンダーの年を設定`** を追加した。

- 日付エリアの先頭列の年を指定すると、以降は**月日だけ**をシートから読み、
  年はマクロが振り直す。月が戻ったところ（12月→1月）で1年繰り上げる
- `0` を入れると補正をやめ、シートの値をそのまま使う（従来どおり）
- レイアウト検証に「年の扱い」と「シートの生値」を表示するようにした

`BuildDateMap` は `BuildColMap` を反転させるだけになり、
日付の読み取りが1か所に集まった。

### 本着日は基礎の下1マス（M00_Config / M05_Plan）

- 本着日 … `MARK_OFS_HONCHAKU`（ブロック先頭 +5 = 基礎の下の行）に黒1マス
- その列だけ、**基礎の色帯を1行上へずらして塗る**（+4/+5 → +3/+4）
- お客様納期 … これまでどおりブロック先頭から縦4マスの青
- 工程の色を消すときは、1行上へ逃がした分も対象にする

### 設定シートを廃止（M00_Config / M02_Masters / M99_Menu）

`M_設定` と `M_工期` を作らないようにした。初期セットアップで**削除**する。

| 元シート | 移した先 |
|---|---|
| `M_設定`（工程表シート名） | ブックに埋め込む「名前」（非表示）。`ボタン_このシートを工程表に設定` で書く |
| `M_工期`（基準式・種類補正・インターバル） | `M02_Masters` の `TermDays` / `TypeCorrection` / `TermInterval` |

- 削除の前に、`M_設定` の B1 に入っていたシート名は設定へ引き継ぐ
- 工期の値を直したいときは `M02_Masters.bas` の `TermDays` 付近を編集する
- 利用者に見えるシートは **`M_業者` / `M_例外日` / `M_工程データ` の3枚**になった

### 色の指定を反映（M00_Config / M02_Masters）

工事店さま指定の RGB に合わせた。

| 色名 | RGB | 用途 | v13 から |
|---|---|---|---|
| 日祝 | 153,204,0 | 日曜・祝日・休業日 | **定数の値が誤っていたのを修正**（153,153,0 → 153,204,0） |
| 青 | 0,102,204 | 協栄（基礎） | 変更なし |
| 緑 | 51,153,102 | 加納（基礎） | **変更**（0,128,0 → 51,153,102） |
| 桃 | 255,0,255 | カサハラ（基礎） | 変更なし |
| 薄橙 | 255,204,153 | 龍壱（基礎） | **変更**（黄 255,255,0 → 薄橙 255,204,153。色名も変更） |
| 茶 | 153,51,0 | 雅建工（躯体） | 変更なし |
| 薄紫 | 204,153,255 | 丸岩・KRK（躯体） | 変更なし |
| 納期の青 | 0,102,204 | お客様納期 | 協栄と同色。塗る位置で区別する |

- 使っていなかった「赤桃」は削除した
- `M_業者` に**版**の列（H列）を足した。版が古いシートは
  `M_業者_旧1` に退避して作り直す（色を直しても取り込み直せる）
- v13 以前の誤った黄緑 RGB(153,153,0) も日祝の色として認識する
  （`IsHolidayColor`）ので、古い塗りが残っていても二重に塗らない

## 実機で確認してほしいこと

1. **`ボタン_カレンダーの年を設定`** → **`ボタン_レイアウトを検証`** で日付が合うか
2. `ボタン_初期セットアップ` で `M_設定` と `M_工期` が消え、シートが3枚になるか
3. 本着日の黒1マスと、その列で基礎の色が1行上にずれているか

## 既知の問題

- `M_業者` を作り直すため、**業者名を手で足していた場合は入れ直しが必要**。
  古い内容は `M_業者_旧1` に残る。
- 設定はブックの「名前」に保存する。**ブックを保存しないと次回に残らない。**
- お客様納期の青は協栄の青と同じ値なので、工程の色をクリアすると納期の青も消える。
  色を塗り直せば戻る。
