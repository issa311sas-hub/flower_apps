# v1 - 2026-08-11 Phase 1 実装（日祝の塗りつぶし・マスタ設計）

コミット: `4d967e1`

## 変更理由
- 過去の工程表7ファイルを解析して構造を確定させ、ルール確定を待たずに
  着手できる部分から実装を始めた。

## 変更内容

### 現行工程表の構造を確定（新規）
- 1物件 = 縦6行。日付エリアでは行オフセットごとに意味が異なることを実測で特定
  - +0 躯体の色帯 / +3 黒帯 / +4,+5 基礎の色帯
- 月の変わり目に日付なしの区切り列が入るため、列番号から日付は計算できない
  - 3行目の実値を読んで日付↔列の対応表を作る方式にした
- 黒セルは2種類あり、基礎行の1マスが契約着工日、もう一方は別工程

### モジュール構成（新規）
| モジュール | 役割 |
|---|---|
| `M00_Config` | 座標定数と共通ヘルパー |
| `M01_Holiday` | 祝日判定（計算で判定。外部データ不要） |
| `M02_Masters` | マスタシートの生成 |
| `M03_PaintHolidays` | 日祝の自動塗りつぶし |
| `M04_Repaint` | 色の塗り直し・業者重複チェック |
| `M99_Menu` | ボタン用エントリポイント |

### 実装した機能
- 日曜・祝日の自動判定と塗りつぶし（ハッピーマンデー・春分秋分・振替休日・国民の休日）
- 物件ごとの祝日例外（非祝日扱い / 臨時休工）
- マスタシートの生成（業者・工期・工程データ・例外日）
- 工程データシートから色を塗り直す機能
- 同一色（＝同一業者）の重複稼働チェック
- レイアウト検証（座標のずれを事前に検出）

## 設計判断
- 工程色が入っているセルは日祝で上書きせず、件数と場所を報告するだけにした。
  日曜へ社内行事の色を載せている実例（2026-04-12 アサヒ会旅行）があったため。
