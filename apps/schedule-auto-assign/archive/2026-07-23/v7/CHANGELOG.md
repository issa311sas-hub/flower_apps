# v7 - 2026-07-23 Beds24 API連携・週次自動実行

## 変更理由
- 毎週のExcel手動エクスポート→スプシ手動貼り付け→手動GAS実行のワークフローを自動化
- 経営者からBeds24 APIアクセスの許可を取得

## 変更内容

### Beds24 API V2連携（新規追加）
- **認証**: 招待コード → リフレッシュトークン → アクセストークンの3段階認証
- **トークン管理**: PropertiesServiceに安全に保存、有効期限内は再利用
- **予約データ取得**: `GET /bookings` でページネーション対応の全件取得
- **ユニットマッピング**: `GET /properties` でroomId一覧を自動取得、設定シートでユニット名と対応付け
- **データ変換**: API応答を既存の6列形式（予約ID, タイトル, 開始日, チェックアウト日, ユニット, ゲスト）に自動変換
- **キャンセル除外**: status=cancelled/deleted の予約は自動除外

### 全自動実行関数（新規追加）
- `runAllAuto()`: API取得 → 割り当て → タイムライン → カレンダー反映を一括実行
- トリガー実行時はUIなしで動作（Logger.logに結果出力）
- 手動実行時はアラートも表示

### 週次トリガー管理（新規追加）
- `setupWeeklyTrigger()`: 設定シートの曜日・時刻で週次トリガーを作成
- `removeWeeklyTrigger()`: トリガー解除
- デフォルト: 毎週月曜6時

### メニュー更新
- 「全自動実行」をメニュートップに追加
- 「Beds24から予約データ取得」を追加（手動でAPI取得のみ実行）
- 「週次自動実行を設定/解除」を追加
- 「Beds24 API接続設定」を追加

### 設定シート更新
- Beds24 API連携セクション追加（接続状態、取得日数、自動実行曜日・時刻）
- ユニットマッピングテーブル追加（roomId → ユニット名の対応表）

## セットアップ手順
1. Beds24管理画面 → 設定 → API → 招待コード発行（bookingsスコープ）
2. スプシメニュー → 🔑 Beds24 API接続設定 → 招待コード入力
3. 設定シートのユニットマッピングでユニット名（b2, s1等）を入力
4. メニュー → ⏰ 週次自動実行を設定
