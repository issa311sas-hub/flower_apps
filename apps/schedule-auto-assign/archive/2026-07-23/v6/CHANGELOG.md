# v6 - 2026-07-23 タイムラインシート追加

## 変更理由
- 経営者から「翌日清掃の自動割り当ては信頼しているが、確認・チェックできるようにしておいてほしい」という要望
- 清掃延期（翌日/翌々日清掃）がどのように発生しているか、視覚的に確認できる手段が必要

## 変更内容

### タイムラインシート（新規追加）
- 「タイムライン」シートにユニット×日付のガントチャートを自動生成
- 割り当て実行（runMatchingMenu / runAll）時に自動更新

### 表示内容
- **行**: ユニット（b2, b3, b4, b5, b6, s1, s2, s3, c4）
- **列**: 予約データの日付範囲（前後1日余白付き）
- **セル内容**:
  - `■` = 宿泊中（青）
  - `CO` = チェックアウト日（オレンジ）
  - `細` / `普` = スタッフ清掃予定（緑）
  - `R` = Rクリーン清掃予定（紫）
  - `?` = 未割当（赤）
  - `…` = 清掃可能期間（黄）：清掃を遅らせられる猶予日

### 色分け
- 青(#CFE2F3): 宿泊中
- オレンジ(#FCE5CD): チェックアウト日
- 緑(#D9EAD3): スタッフ清掃
- 紫(#E8D5F5): Rクリーン清掃
- 赤(#FBEAE6): 未割当
- 黄(#FFF2CC): 清掃猶予期間

### ヘッダ
- 1行目: 日付（M/d形式）
- 2行目: 曜日（日曜=赤背景、土曜=青背景）
- 1列目・ヘッダ2行は固定表示（フリーズ）

### 凡例
- シート下部に凡例行を自動表示
