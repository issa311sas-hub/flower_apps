# schedule-auto-assign

民泊清掃予定の自動割り当てシステム。

## 概要

沖縄の民泊事業(9ユニット)の清掃スケジュールを自動化する。
Beds24 API から取得した予約データと、Googleカレンダー上のスタッフ出勤可否を突合し、清掃担当を自動割り当てしてカレンダーに反映する。日次トリガーで全工程が自動実行される。

## 主な機能

- **Beds24 API V2連携**: 予約データを自動取得（Excelの手動貼り付けも可能）
- **清掃期限の自動判定**: 次の予約の開始日から逆算。上限はチェックアウト+2日（害虫防止）
- **多段階の割り当て**: 細田さん → 普久原さん → 福田さん → 未割当 → Rクリーン（外注、14日以内）
- **差分同期**: 変更のあった予定だけカレンダーを更新。手動でのカレンダー編集は保持
- **タイムラインシート**: ユニット×日付のガントチャートで清掃の延期状況を目視確認
- **日次自動実行**: GASの時間ベーストリガー（既定 毎日6時）

## 技術スタック

- Google スプレッドシート（管理画面・データ入力）
- Google Apps Script（マッチングロジック・自動実行）
- Google Calendar API（スタッフ予定の読み取り・割り当て結果の書き込み）
- Beds24 API V2（予約データ取得）
